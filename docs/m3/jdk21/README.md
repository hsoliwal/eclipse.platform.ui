# M3JDK21 compatibility (Java 21) — eclipse.platform.ui

Status: **GATE_GREEN** (branch `m3/jdk21-compat-20261020`, generated by `scaffold_branch.sh` on 2026-10-20T10:19Z).

Upstream master moved these bundles to JavaSE-25 after the 2026-09 release. M3JDK21 is a JDK 21, so this branch
keeps them at Java 21: the bundle metadata says 21 and the sources use no Java 22+ syntax or API.
Java 25 is not widely adopted yet, and most Maven plugins support Java 21 (user, 2026-10-20), so Java 21 is the
level the whole programme builds and runs on. Rule: VIEWPORT_AGENT_BRIEF rule 30.

## What the recipe changes

`apply_jdk21.sh <worktree> BUNDLES.txt` (text lane, fixed point, CR bytes kept):

1. `META-INF/MANIFEST.MF`: `Bundle-RequiredExecutionEnvironment: JavaSE-2x` becomes `JavaSE-21`.
2. `.classpath`: the JRE container becomes `JavaSE-21`.
3. `.settings/org.eclipse.jdt.core.prefs`: compiler source, compliance and target platform become 21.
4. `build.properties`: `jre.compilation.profile` becomes `JavaSE-21`.
5. Java sources: every unnamed variable `_` (lambda parameter, catch parameter, try resource, local, pattern)
   becomes `unused`, `unused2`, ... (`unnamed_to_named.awk`). Strings, char literals, text blocks and comments
   are masked, so `"_"`, `'_'` and Javadoc examples stay as they are.

## Gate

`compile_gate.sh eclipse.platform.ui 25 base25` on the original sources, then the recipe, then `compile_gate.sh eclipse.platform.ui 21 jdk21`.
Both runs use JDK 25 javac (attribution and flow only, no class files) against the newest jar of every bundle in
the p2 pool. Errors present in both runs are classpath noise (master APIs newer than the pool). The residue is
what Java 21 rejects; it must be empty.

## Fill (next leaves)

1. Residue rows: rename collisions (`unused` already defined) get the next free suffix at that line; Java 22+
   API calls get a Java 21 equivalent, or a backport row in M3jdk21 `m3/backports` when the API is worth keeping.
2. After every merge from upstream master: re-run the recipe (fixed point) and the gate.
3. Runtime: launch on M3JDK21 once a Windows image exists; Temurin 21.0.12.1 is the stand-in
   (`-Dosgi.requiredJavaVersion=21`).

Donor decisions: FOSS_REUSE_DECISION.tsv. Census of the Java 22+ lines before the recipe: CENSUS.tsv.

## Machine Oriented Programming (MOP)
