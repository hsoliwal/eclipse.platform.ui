# JFace M3 forwarding receiver

Five original JFace classes forward 14 array call sites to 13 internal M3 atoms.
Read tooling/synexia-openrewrite-recipes/recipe-crates/m3-jface-array-forwarding-20261017/README.md
for exact coverage, tests, pins, licenses and portable reproduction. The source recipe
is owned by hsoliwal/com.synexia; this is a pinned tooling mirror. Production files were
generated by that recipe and compiled/tested, including live Equinox resolution.

This pass does not implement the entire Eclipse framework. Full Tycho/platform gates
are pending; the PR is draft. Current APIs and callback contracts remain the boundaries.
